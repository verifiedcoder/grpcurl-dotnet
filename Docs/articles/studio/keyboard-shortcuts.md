# Keyboard shortcuts

Studio is fully keyboard-operable. The shortcuts below work app-wide, including while a code editor holds
focus. On macOS and Linux the same `Ctrl`-based chords apply.

## Run and edit

| Action | Shortcut |
| --- | --- |
| Invoke / Start stream / Execute (active tab) | `Ctrl+Enter` |
| Cancel the running call or stream | `Ctrl+.` |
| Format the request body / GraphQL variables (JSON) | `Ctrl+Shift+F` |
| Save the request (in an invocation tab) | `Ctrl+S` |
| Toggle a `#` comment over the selection (GraphQL editor) | `Ctrl+/` |
| Open descriptor-aware completion (GraphQL editor) | `Ctrl+Space` |
| Refresh descriptors for the active connection | `F5` |

## Tabs

| Action | Shortcut |
| --- | --- |
| New request tab from the selected method | `Ctrl+T` |
| Close the active tab | `Ctrl+W` |
| Next / previous tab | `Ctrl+Tab` / `Ctrl+Shift+Tab` |
| Next / previous tab (alternate) | `Ctrl+PageDown` / `Ctrl+PageUp` |

## Navigation and focus

| Action | Shortcut |
| --- | --- |
| Cycle focus across zones (sidebar → document → inspector → console → status bar) | `F6` / `Shift+F6` |
| Focus the explorer filter (second press restores focus) | `Ctrl+L` |
| Focus the environment switcher | `Ctrl+E` |
| Command palette | `Ctrl+K` |
| Open History | `Ctrl+H` |
| Open Settings | `Ctrl+,` |
| Dismiss popup / flyout / cancel a cell edit | `Esc` |

`Esc` resolves innermost-first (completion popup → editor selection → flyout → cell edit) and never
closes a tab or cancels an in-flight call — use `Ctrl+W` and `Ctrl+.` for those.

## Panes and layout

| Action | Shortcut |
| --- | --- |
| Toggle sidebar | `Ctrl+B` |
| Toggle console | `Ctrl+J` |
| Toggle inspector | `Ctrl+I` |
| Focus mode (collapse all panes) | `Ctrl+Shift+M` |

## Workspace

| Action | Shortcut |
| --- | --- |
| New workspace | `Ctrl+N` |
| Open workspace | `Ctrl+O` |
| Save / Save As | `Ctrl+S` / `Ctrl+Shift+S` |
